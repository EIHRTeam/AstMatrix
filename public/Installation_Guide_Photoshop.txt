	AstMatrix for Photoshop Installation Guide

Windows Installer (.exe)

		Download AstMatrix-Photoshop-<version>-Setup.exe from:
		https://github.com/EIHRTeam/AstMatrix/releases/latest
		Close Photoshop and run setup on Windows 10/11 x64.
		Requires Photoshop 26.0+ and its Adobe WebView dependencies.
		Setup first invokes the existing Adobe Unified Plugin Installer
		Agent (UPIA). If it is missing, cannot launch, or reports a
		recognized environment failure, setup tries experimental extraction
		to %APPDATA%\Adobe\UXP\Plugins\External\1f4db629_<version>\.
		Extraction only confirms that files were deployed. Restart
		Photoshop and verify that Plugins > AstMatrix is available.
		Adobe's internal plugin registration JSON is never modified.
		Cancellation, invalid packages, incompatible hosts, conflicting
		copies, and unresolved UPIA operations do not trigger extraction.
		Run a newer installer to upgrade; downgrades are rejected.
		Uninstall through Windows Installed apps. Externally updated or
		modified plugins are preserved. Setup never force-closes Adobe apps.
		The EXE is unsigned and includes all plugin resources.
		Setup does not download UPIA, plugins, or Adobe runtimes.
		Diagnostics: %LOCALAPPDATA%\AstMatrix\Installers\Photoshop\installer.log

	For sections B, C, and D, download the latest Photoshop .ccx
	package from:
	https://github.com/EIHRTeam/AstMatrix/releases/latest

A. Install via Adobe Creative Cloud

	1. Make sure Adobe Creative Cloud is installed and that you are
	   signed in with your Adobe account.

	2. Open the Adobe Exchange page:
	   https://exchange.adobe.com/apps/cc/1f4db629/astmatrix-for-photoshop
	   Or search "AstMatrix for Photoshop" in the Creative Cloud
	   desktop app.

	3. Install the plugin.

	4. Open Photoshop (or restart it completely if it is already
	   running), then select "Plugins" > "AstMatrix" to
	   launch the plugin.



B. Install via Adobe Creative Cloud (.ccx File)

	1. Make sure Adobe Creative Cloud is installed and that you are
	   signed in with your Adobe account.

	2. Double-click the downloaded .ccx file, or open the .ccx
	   file using the Adobe Creative Cloud desktop app.

	3. Confirm the non-marketplace plugin installation prompt by
	   clicking "Install" (or "Install locally", depending on your
	   Creative Cloud version).

	4. Open Photoshop (or restart it completely if it is already
	   running), then select "Plugins" > "AstMatrix" to
	   launch the plugin.



C. Install via Adobe Universal Plugin Installer Agent (UPIA)

	1. Make sure Adobe Creative Cloud version 5.7 or later is
	   installed.

	2. Run the command for your operating system. Replace the example
	   .ccx path with the path to your downloaded file, keeping the
	   quotation marks:

		2.1.1 On Windows, press the Windows logo key + R to open
		      the Run dialog, type "cmd", and click "OK".

		2.1.2 On macOS, press Command + Space to open Spotlight,
		      then search for and open "Terminal.app".

		2.2.1 On Windows, run the following command in CMD:
			"C:\Program Files\Common Files\Adobe\Adobe Desktop Common\RemoteComponents\UPI\UnifiedPluginInstallerAgent\UnifiedPluginInstallerAgent.exe" /install "C:\path\to\AstMatrix.ccx"

		2.2.2 On macOS, run the following command in Terminal:
			"/Library/Application Support/Adobe/Adobe Desktop Common/RemoteComponents/UPI/UnifiedPluginInstallerAgent/UnifiedPluginInstallerAgent.app/Contents/MacOS/UnifiedPluginInstallerAgent" --install "/path/to/AstMatrix.ccx"

	   See Adobe's "How to Install UXP Plugins Using Command
	   Line Tools":
	   https://blog.developer.adobe.com/en/publish/2022/03/how-to-install-uxp-plugins-using-command-line-tools

	3. Open Photoshop (or restart it completely if it is already
	   running), then select "Plugins" > "AstMatrix" to
	   launch the plugin.



D. Manual Extraction (Experimental)

	1. Open the .ccx file using a ZIP archive utility (e.g.,
	   7-Zip, ShichiZip, or Keka).

	2. Extract its contents to the following directory for your
	   operating system:
		   Windows: %APPDATA%\Adobe\UXP\Plugins\External\1f4db629_<version>\
	   macOS: ~/Library/Application Support/Adobe/UXP/Plugins/
		   On Windows, create the plugin-specific directory above and
		   place manifest.json directly inside it, without another folder.
		   Extraction may not register the plugin in current Photoshop.
		   If it does not load, use Creative Cloud or UPIA instead.
		   Do not edit Adobe's internal plugin registration JSON or keep
		   extracted and Adobe-managed copies installed together.

	3. Open Photoshop (or restart it completely if it is already
	   running), then select "Plugins" > "AstMatrix" to
	   launch the plugin.
