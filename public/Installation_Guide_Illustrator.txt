	AstMatrix for Illustrator Installation Guide

A. Install via Adobe Creative Cloud

	1. Make sure Adobe Creative Cloud is installed and that you are
	   signed in with your Adobe account.

	2. Open the Adobe Exchange page:
	   https://exchange.adobe.com/apps/cc/206104/astmatrix
	   Or search "AstMatrix" in the Creative Cloud desktop app.

	3. Install the plugin, then follow section D to launch it.



B. Install Manually

	1. Download the latest Illustrator .zip package from:
	   https://github.com/EIHRTeam/AstMatrix/releases/latest

	2. Make sure Adobe Illustrator is installed and completely closed.

	3. Open the downloaded .zip file using a ZIP archive
	   utility (e.g., 7-Zip, ShichiZip, or Keka).
	   Its contents start with "CSXS/manifest.xml", without an
	   enclosing "AstMatrix" folder.

	4. Create an "AstMatrix" folder in the following directory,
	   then extract all archive contents into it:
	   Windows: %APPDATA%\Adobe\CEP\extensions\
	   macOS: ~/Library/Application Support/Adobe/CEP/extensions/

	   Create the "extensions" folder if it does not already exist.

	5. Make sure the final manifest path is
	   "extensions/AstMatrix/CSXS/manifest.xml", without an extra
	   nested folder.

	6. Follow section C to enable unsigned CEP extensions, then
	   follow section D to launch the plugin.



C. Enable Unsigned CEP Extensions (Manual Installation Only)

	1. Because the manually installed plugin is unsigned, enable CEP
	   debug mode to allow Illustrator to load it.

	2. Set "PlayerDebugMode" for the CEP version used by Illustrator:

		2.1.1 On Windows, press the Windows logo key + R,
		      type "regedit", and click "OK".

		2.1.2 Navigate to the following registry key:
		      HKEY_CURRENT_USER\Software\Adobe\CSXS.12

		2.1.3 If the key does not exist, create it. Then create
		      a String Value (REG_SZ) named "PlayerDebugMode"
		      and set its value to "1".

		2.2.1 On macOS, press Command + Space to open Spotlight,
		      then search for and open "Terminal.app".

		2.2.2 Run the following command in Terminal:
		      defaults write com.adobe.CSXS.12 PlayerDebugMode 1

	3. The examples above use CEP 12. If your Illustrator version
	   uses a different CEP version, replace "12" with the
	   corresponding version number (e.g., "11" for CEP 11).

	4. Enable this setting only for plugins from sources you trust.



D. Launch the Plugin

	1. Open Illustrator (or restart it completely if it is already
	   running), then select "Window" > "Extensions" > "AstMatrix"
	   to launch the plugin.
